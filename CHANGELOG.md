### Added
 * **Symfony 6.4 LTS Compatibility (`^6.4 | ^7.2 | ^8.0`, PHP `>= 8.3`):** Added dual `UriSigner` support in `ShareLinkService` (`verify()` on Symfony 7.1+/8.x and HMAC-signed `_expiration` + `checkRequest()` fallback on Symfony 6.4 LTS) and added `PHP 8.3 + Symfony 6.4.*` to GitHub Actions CI.

 * **Compact JSON Wire Format (`compact=1`) & Smart Hybrid Pagination (`hybridLimit=500`):** Reduces `/api/list` JSON payloads by ~55–68% via shared `urlBases` and omitted default/null fields; directories with `<= 500` items keep 0ms client-side search/sort/pagination while larger directories automatically switch to server-side pagination in both `ApiController::list()` and SSR `BrowserComponent`.
 * **Pre-Minified Production Asset Pipeline (`assets/dist/` via `esbuild`):** Reduced AssetMapper & Encore asset footprint by 45.3% minified (`764.8 KB → 418.2 KB`, `~80.3 KB` Brotli total) with zero-config `autoimport` in `assets/package.json`, automatic `assets/dist/` mapping in `FileManagerBundle::prependAssetMapper()`, `composer assets:build` / `assets:check`, and CI drift enforcement.
 * **EasyAdmin 5 Compatibility:** Widened `FileManagerField::new()` `$label` parameter type to `TranslatableInterface|string|bool|null` (contravariant — compatible with both EasyAdmin 4 and EasyAdmin 5).
 * **LiveUX Branded About Modal & Locked Attribution:** Embedded optimized `liveux-logo.webp` into the About modal and made the About modal & GitHub repository link always visible (non-configurable).
 * **12 Built-in Native UI Languages + Native Arabic RTL (`493/493` Keys & `%placeholder%` Parity):** Expanded UI translations from 3 (`en`, `tr`, `fr`) to 12 native-quality global languages (`en`, `tr`, `fr`, `de`, `es`, `ar` RTL, `it`, `pt`, `nl`, `pl`, `ja`, `zh_CN`), enforced by `TranslationParityTest` for exact key, non-empty value, and `%placeholder%` parity, plus RTL toolbar/select/folder-badge/BiDi polish in `core.css`.
 * **Complete 12-Language Documentation (`docs/{en,tr,fr,de,es,ar,it,pt,nl,pl,ja,zh_CN}/`, 253 Guides):** Full 21-guide documentation parity across all 12 languages (including all 7 cloud storage guides, 7 WYSIWYG editors, EasyAdmin 4/5, `CollectionType`/`LiveCollectionType`, Doctrine, Symfony AI, Asset Usage Guard, and AI Agent Skills) with a unified 12-language switcher bar.
 * **Packagist Optimization:** Added `/docs export-ignore` to `.gitattributes` (and removed accidental `/assets/package.json export-ignore`) so Composer installs stay ultra-lightweight while keeping Symfony UX metadata intact.

### Security

### Security
 * Centralized `FileSecurityGuard` blocking executable extensions, double extensions, dotfiles (`.env`, `.htaccess`, `.meta.json`), Windows reserved device names (`CON`, `NUL`, `COM1`–`LPT9`, `LPT1`–`LPT9`), trailing dots/spaces, and direct `.trash`/excluded path access.
 * `PathNormalizer` blocking path traversal (`..`), null bytes/control characters, stream wrappers (`php://`, `phar://`), drive paths, and excessive nesting depth (`> 32`).
 * `FileManagerVoter` RBAC permissions per action and per profile + `CsrfRequestValidator` (`X-LiveUX-FM-CSRF`).
 * `SvgSanitizer` rejecting XXE/DTD (`<!DOCTYPE`, `<!ENTITY`), XML Processing Instructions, SMIL animation tags, dangerous CSS `@import`/URLs, `xml:base`, and event handler attributes.
 * SSRF-hardened `RemoteUrlImporter` using binary `inet_pton()` inspection blocking loopback, private, link-local, CGNAT (`100.64.0.0/10`), `0.0.0.0/8`, IPv4-mapped IPv6 (`::ffff:`), NAT64 (`64:ff9b::`), userinfo credentials, non-80/443 ports, and unsafe redirects.
 * Decompression-bomb and ImageTragick delegate guards in `GdThumbnailDriver`, `ImagickThumbnailDriver`, and `ImageEditorController` (`<= 8192×8192`, `<= 40MP`).
 * Generation-counter directory cache invalidation (`DirectoryCacheManager`) preventing full host-application cache wipes on non-taggable PSR-6 pools.
 * Active MIME download hardening (`X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'none'; sandbox`, forced attachment disposition for HTML/SVG/JS/XML; strict `object-src 'self'; frame-ancestors 'self'` CSP for verified inline PDFs).
 * Comprehensive DOM XSS & Strict CSP hardening: zero inline event handlers across all 33 Twig templates (`onclick`-free for `script-src 'self'` CSP), WHATWG `/\` backslash & control-char URL guard across `BrowserController`, `PickerController`, `DialogController`, and all 3 WYSIWYG adapters (`TinyMCE`, `CKEditor 5`, `Tiptap`), `X-LiveUX-FM-Dialog: 1` + DOMParser fragment scrubbing in `DialogController`, client-side defense-in-depth `sanitizeInlineSvg()`, prototype-lookup isolation, and `DownloadController`-routed PDF Lightbox preview with `referrerpolicy="no-referrer"`.

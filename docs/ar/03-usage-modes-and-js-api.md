# 03 — أوضاع الاستخدام وواجهة JavaScript API

[← السابق: 02 — التهيئة وملفات التعريف](02-configuration-and-profiles.md) | [فهرس التوثيق](README.md) | [التالي: 04 — السمات ومجموعات الأيقونات والتخصيص →](04-themes-icons-and-customization.md)

يمكنك تضمين LiveUX FileManagerBundle **مباشرةً داخل أي صفحة (Inline)**، أو فتحه في **نافذة منبثقة (Modal)** متوسّطة، أو سحبه كلوح جانبي **OffCanvas** من أربعة اتجاهات، أو استدعاؤه برمجياً من أي مكان عبر **واجهة JavaScript Promise API**.

> [!TIP]
> **أي وضع ينبغي أن أختار؟**  
> - **التضمين المباشر (`inline`):** صفحات *"مكتبة الوسائط"* المخصّصة حيث يملأ مدير الملفات مساحة المحتوى الرئيسية.  
> - **النافذة المنبثقة (`modal`):** نافذة متوسّطة تُفتح من زر *"اختر صورة"* أثناء تحرير منتج أو مقال — وتُغلق فور اختيار المستخدم للأصل.  
> - **اللوح الجانبي (`offcanvas`):** لوح منزلق حديث ينفتح من أي حافة (`start` أو `end` أو `top` أو `bottom`) مع إبقاء نموذجك مرئياً في الخلفية.  
> - **واجهة JavaScript API (`window.LiveUXFileManager.open()`):** تشغيل المنتقي من أي زر HTML مخصّص أو مكوّن React/Vue/Alpine أو شيفرة JavaScript خالصة دون الحاجة إلى Symfony Forms.

## 1. الوضع المضمّن (`inline`) — TwigComponent

![عرض مدير الملفات المضمّن داخل الصفحة](../images/browser-light.png)

لا يتطلب تضمين مدير ملفات كامل سوى استدعاء Twig واحد. ضعه داخل حاوية بارتفاع صريح (مثل `680px` أو `calc(100vh - 140px)`):

```twig
<div style="height: 680px;">
    {{ component('LiveUX:FileManager:Browser', {
        profile: 'default',
        mode: 'inline'
    }) }}
</div>
```

أو باستخدام صيغة وسوم مكوّنات Symfony UX `<twig:...>`:

```twig
<div style="height: 680px;">
    <twig:LiveUX:FileManager:Browser
        profile="products"
        mode="inline"
        theme="flowbite"
        iconSet="macos"
        typeFilter="image"
        locale="ar"
    />
</div>
```

### جميع خصائص (Props) مكوّن `Browser`

| الخاصية (Prop) | النوع | القيمة الافتراضية | الوصف |
| :--- | :--- | :--- | :--- |
| `profile` | `string` | `'default'` | مفتاح ملف التعريف المعرّف في `liveux_file_manager.yaml`. |
| `volume` | `?string` | `null` | مفتاح وحدة التخزين الابتدائية (`null` يفتح أول وحدة تخزين في ملف التعريف). |
| `path` | `string` | `''` | المجلد الفرعي الابتدائي (مثل `'products/2026'`). |
| `multiple` | `bool` | `false` | تفعيل وضع اختيار الملفات المتعدّدة. |
| `mode` | `string` | `'inline'` | `'inline'` أو `'modal'` أو `'offcanvas'`. |
| `typeFilter` | `string` | `'all'` | فلتر النوع الابتدائي: `'all'` أو `'folder'` أو `'image'` أو `'doc'` أو `'video'`. |
| `theme` | `?string` | `null` | تجاوز السمة وقت التشغيل (يقبل السمات الـ 9 المدمجة: `bootstrap5` و`tailwind` و`shadcn` و`flowbite` و`daisyui` و`tabler` و`preline` و`material` و`unstyled`). أما سمات CSS/Twig المخصّصة فتُهيّأ في YAML. |
| `iconSet` | `?string` | `null` | تجاوز مجموعة الأيقونات وقت التشغيل (`classic` و`windows11` و`macos` و`linux` و`minimal` و`vscode`). أما مجلدات SVG المخصّصة فتُهيّأ في YAML. |
| `locale` | `?string` | `null` | تجاوز اللغة وقت التشغيل عبر **12 لغة واجهة مدمجة** (`en` و`tr` و`fr` و`de` و`es` و`ar` و`it` و`pt` و`nl` و`pl` و`ja` و`zh_CN`) أو أي صيغة BCP-47 / POSIX (مثل `'ar'` أو `'zh_Hans_CN'`). |

## 2. Modal وOffCanvas — واجهة JavaScript Promise API البرمجية

تُحقن حاوية `DialogHost` تلقائياً في كل استجابة HTML كاملة (`defaults.auto_inject_dialog_host: true`). ويمكنك استدعاء `window.LiveUXFileManager.open()` باستخدام `async/await` من أي صفحة.

### جميع خيارات `open(options)`

| الخيار | النوع | القيمة الافتراضية | الوصف |
| :--- | :--- | :--- | :--- |
| `profile` | `string` | `'default'` | اسم ملف التعريف المراد فتحه. |
| `volume` | `?string` | `null` | مفتاح وحدة التخزين الابتدائية. |
| `path` | `string` | `''` | مسار المجلد الابتدائي (مثل `'banners'`). |
| `mode` | `'modal'\|'offcanvas'` | `'modal'` | نافذة منبثقة متوسّطة أو لوح جانبي منزلق OffCanvas. |
| `position` | `'start'\|'end'\|'top'\|'bottom'` | `'end'` | الحافة التي ينزلق منها اللوح عند `mode: 'offcanvas'` (`start` = البداية، `end` = النهاية؛ تنعكس تلقائياً في لغات RTL). |
| `mobileMode` | `'auto'\|'fullscreen'\|'sheet'` | `null` *(من ملف التعريف)* | يتجاوز تخطيط النافذة على شاشات الجوال (`<= 767.98px`). |
| `multiple` | `bool` | `false` | `false` = ملف مفرد، `true` = ملفات متعددة. |
| `type` / `filetype` | `'all'\|'folder'\|'image'\|'doc'\|'video'\|'media'` | `'all'` | يفتح مدير الملفات مصفّى مسبقاً على فئة ملفات معيّنة (`filetype` اسم بديل للتوافق مع TinyMCE؛ وتُحوّل `'media'` تلقائياً إلى `'video'`). |
| `theme` | `?string` | `null` | تجاوز وقت التشغيل لأي من السمات الـ 9 المدمجة (مسارات قوالب Twig المخصّصة محصورة في YAML على جانب الخادم لدواعي الأمان). |
| `iconSet` | `?string` | `null` | تجاوز وقت التشغيل لأي من مجموعات الأيقونات الـ 6 المدمجة. |
| `locale` | `?string` | `null` | تجاوز اللغة وقت التشغيل (`'ar'` أو `'en'` أو `'tr'` أو `'fr'` أو `'de'` أو `'ja'` أو `'zh_CN'` وغيرها). |

### مثال عملي: حقل `<input>` مخفي + معاينة حية للصورة (دون Symfony Form)

ضع هذا المقطع في أي صفحة HTML أو Twig وسيعمل فوراً:

```html
<!-- 1. حقل مخفي + معاينة حية + زر الفتح -->
<div>
    <input type="hidden" id="cover-url" name="cover_url" value="">
    <img id="cover-preview" src="" alt="معاينة" style="display:none; max-width:220px; border-radius:8px; margin-bottom:8px;">
    <br>
    <button type="button" id="cover-pick-btn">اختيار صورة الغلاف</button>
</div>

<script>
document.getElementById('cover-pick-btn').addEventListener('click', async () => {
    const selected = await window.LiveUXFileManager.open({
        profile: 'default',
        mode: 'offcanvas',
        position: 'end',
        mobileMode: 'auto',
        multiple: false,
        type: 'image',       // فتح مدير الملفات مصفّى مسبقاً على الصور
        theme: 'shadcn',
        iconSet: 'windows11',
    });

    // ضغط المستخدم ESC أو أغلق النافذة دون اختيار أي ملف
    if (selected.length === 0) {
        return;
    }

    const file = selected[0];
    document.getElementById('cover-url').value = file.url;

    const img = document.getElementById('cover-preview');
    if (file.isImage) {
        img.src = file.url;
        img.alt = file.meta?.alt || file.name;
        img.style.display = 'block';
    }
});
</script>
```

### مقاطع سريعة للأوضاع

```html
<!-- نافذة منبثقة متوسّطة -->
<button type="button" onclick="window.LiveUXFileManager.open({ mode: 'modal' })">فتح نافذة منبثقة</button>

<!-- لوح جانبي منزلق من جهة النهاية (OffCanvas) -->
<button type="button" onclick="window.LiveUXFileManager.open({ mode: 'offcanvas', position: 'end' })">لوح جانبي</button>

<!-- لوح سفلي منزلق (OffCanvas) -->
<button type="button" onclick="window.LiveUXFileManager.open({ mode: 'offcanvas', position: 'bottom' })">لوح سفلي</button>
```

> [!NOTE]
> **سلوك الإلغاء:** إذا أغلق المستخدم النافذة دون اختيار ملف (بالضغط على `ESC` أو زر الإغلاق أو النقر على الخلفية)، فإن الـ Promise **لا يُرفض (does not reject)** — بل يُحسم بنظافة إلى مصفوفة فارغة (`[]`).
>
> **التجاوب مع الجوال (`mobileMode` / `ui.mobile_dialog_mode`):** على الشاشات التي لا يتجاوز عرضها `767.98px` تتكيّف النافذة تلقائياً: في وضع `'auto'` تُفتح النوافذ المنبثقة والألواح الجانبية (`start`/`end`) بملء الشاشة (`100dvh`)، بينما تُفتح الألواح السفلية والعلوية (`bottom`/`top`) كألواح أصلية مستديرة الحواف بمقبض سحب. وتبدأ شجرة المجلدات مطوية على الجوال وتنزلق عند النقر.

| لوح OffCanvas على سطح المكتب (`position: 'end'`) | اللوح السفلي على الجوال (`mobileMode: 'sheet'`) |
| :---: | :---: |
| ![عرض OffCanvas على سطح المكتب](../images/offcanvas-desktop.png) | ![عرض اللوح السفلي على الجوال](../images/mobile-sheet.png) |

### بنية كائن الملف المُرجَع

تُحسم دالة `window.LiveUXFileManager.open()` إلى مصفوفة من الكائنات بالبنية التالية:

```json
[
    {
        "kind": "file",
        "path": "products/matte-black-tumbler.webp",
        "url": "/uploads/products/matte-black-tumbler.webp",
        "name": "matte-black-tumbler.webp",
        "extension": "webp",
        "isImage": true,
        "meta": {
            "alt": "كوب حافظ للحرارة أسود مطفي من الفولاذ المقاوم للصدأ",
            "title": "Tumbler Pro",
            "caption": "قارورة معزولة بالتفريغ سعة 500 مل",
            "tags": ["كوب", "أدوات شرب"],
            "focalPoint": { "x": 0.5, "y": 0.4 }
        }
    }
]
```

*(ملاحظة: في وحدات التخزين ذات `private: true`، يشير الحقل `url` إلى نقطة النهاية المحمية بـ RBAC وهي `/_liveux-file-manager/download?...&inline=1`.)*

### أحداث DOM المخصّصة

إضافةً إلى انتظار `window.LiveUXFileManager.open()`، يمكنك الاشتراك مباشرةً في أحداث دورة حياة النافذة على كائن `window`:

| حدث DOM (`window.addEventListener`) | متى يُطلق | محتوى `event.detail` |
| :--- | :--- | :--- |
| `liveux:file-manager:open` | عند إرسال طلب فتح نافذة (الجسر بين `file_manager_api.js` و`dialog_controller.js`). | خيارات `open()` + `requestId` |
| `liveux:file-manager:dialog-opened` | فور فتح النافذة وتركيب محتواها في الصفحة. | `{ mode, position, profile }` |
| `liveux:file-manager:selected` | عندما يؤكّد المستخدم اختياره (أو يلغي النافذة). | `{ items: [...], requestId }` |

```javascript
window.addEventListener('liveux:file-manager:selected', (event) => {
    console.log('عدد العناصر المختارة:', event.detail.items.length);
});
```

## 3. المزايا المدمجة للمستخدم النهائي

- **قوائم السياق المضغوطة (Context Menus):**
  - *على ملف أو مجلد:* شريط إجراءات سريعة بأيقونات SVG من صف واحد بأسلوب Windows 11 (`قص` و`نسخ` و`إعادة التسمية` و`تنزيل`/`تثبيت` و`حذف`) تليه إجراءات مجمّعة بنقرة واحدة (معاينة، تعديل الصورة، المعلومات ونقطة التركيز، استخراج الأرشيف، نسخ الرابط، إنشاء رابط مشاركة، نقل/نسخ، تكرار، لون المجلد وأيقونته).
  - *على المساحة الفارغة:* شريط تنقل سريع علوي (`← → ↑ ↻`)، مجلد جديد، رفع هنا، لصق هنا، تحديد الكل، الترتيب، والعناصر في الصفحة. *(وتتواجد خيارات ملء الشاشة واختصارات لوحة المفاتيح وحول الحزمة داخل قائمة **⚙ الإعدادات** في شريط الأدوات.)*
  - *الجوال / اللمس:* تُفتح كلوح سفلي ملائم للمس عبر زر `⋯` الموجود على كل بطاقة.
- **العارض الشامل (Lightbox v2) ولوحة المعاينة والتفاصيل الجانبية:**
  - **الصور:** التنقل بين المعرض (`←`/`→`)، أدوات التكبير والتصغير (`-` / `100%` / `+`)، ومؤشر نقطة التركيز.
  - **الفيديو (`.mp4` و`.webm` و`.ogv` و`.mov` و`.m4v`):** مشغّل `<video controls>` حي في لوحة التفاصيل + معاينة ملء الشاشة في Lightbox + دعم التقديم والترجيع عبر `HTTP 206 Partial Content` على وحدات التخزين الخاصة (قابل للتعطيل لكل ملف تعريف عبر `ui.allow_video_preview`).
  - **PDF (`.pdf`):** عارض PDF معزول داخل `<iframe>` ضمن Lightbox (قابل للتعطيل عبر `ui.allow_pdf_preview`).
  - **الصوت (`.mp3` و`.wav` و`.ogg` و`.m4a` و`.flac` و`.aac`) والنصوص/الشيفرات (`.txt` و`.md` و`.json` و`.yaml` و`.csv` و`.css` و`.sql` وغيرها — بحد أقصى 64 كيلوبايت).**
  - في وضع `inline`، يفتح **النقر المزدوج** على أي ملف قابل للمعاينة (أو الضغط على `Space`) العارض المنبثق Lightbox فوراً.
- **طابور الرفع الذكي (إيقاف مؤقت / استئناف / إلغاء مؤكّد):**
  - رفع الملفات **أو هياكل مجلدات كاملة** (`webkitGetAsEntry`) عبر السحب والإفلات، أو لصق الصور مباشرةً من الحافظة عبر `Ctrl+V`.
  - يعرض الرفع المجزّأ عدّادات الأجزاء لحظياً (`2/5 • 40%`)، وأزرار **إيقاف مؤقت (`⏸`) / استئناف (`▶`)** بنقرة واحدة، و**إلغاء (`✕`)** محمي بتأكيد، وإجراءات جماعية **إيقاف الكل مؤقتاً / إلغاء الكل**، مع تنظيف تلقائي للأجزاء المؤقتة غير المكتملة على الخادم عند الإلغاء.
- **التحديد المتعدّد (بما فيه التحديد بالسحب المربّع) والحافظة والبحث الشامل:**
  - انقر واسحب على المساحة الفارغة لرسم **مستطيل تحديد (Marquee / Lasso)** حول عدة ملفات ومجلدات (اضغط `Ctrl`/`Cmd` للإضافة إلى التحديد الحالي).
  - التحديد بالنطاق عبر `Shift+Click`، وتبديل العناصر عبر `Ctrl+Click`، وتحديد الكل عبر `Ctrl+A`، والنسخ/القص/اللصق `Ctrl+C`/`Ctrl+X`/`Ctrl+V` عبر المجلدات وحتى بين وحدات التخزين المختلفة.
  - **رؤوس أعمدة قابلة للترتيب في عرض القائمة:** انقر على **الاسم** أو **النوع** أو **الحجم** أو **التاريخ** في عرض القائمة للتبديل بين الترتيب التصاعدي والتنازلي.
  - **منزلق حجم البطاقات الحي وبطاقات المجلدات:** عدّل حجم البطاقات لحظياً (`96 px – 320 px`) وبدّل بين بلاطات المجلدات المضغوطة (`tile`) وبطاقات المجلدات الكاملة (`card`) من قائمة الإعدادات (`⚙`).
  - فعّل زر البحث الشامل في شريط البحث للبحث التكراري في جميع المجلدات الفرعية، بما في ذلك `#الوسوم` والنص البديل `alt`.
  - مجلدات **⭐ الوصول السريع المثبّتة** في الشريط الجانبي، ونافذة **تفاصيل استهلاك التخزين والحصة** القابلة للنقر، ومبدّل وضع الألوان **تلقائي / فاتح / داكن**.
- **التحقق الفوري (0ms) من دقة الصور ونسبة أبعادها (`image_constraints`):** عند تهيئة شروط الأبعاد أو نسبة العرض إلى الارتفاع (`1:1` و`16:9` وغيرها)، تُرفض الصور غير المطابقة فوراً في المتصفح قبل الرفع (ويُعاد التحقق منها على الخادم).
- **البيانات الوصفية التحريرية ونقطة التركيز وروابط المشاركة الموقّعة:**
  - تعديل `alt` و`title` و`caption` و`#الوسوم`، ومنتقي **نقطة التركيز** `[x, y]` بالنقر المباشر على الصورة، وزر **✨ اقتراح بالذكاء الاصطناعي** الاختياري.
  - توليد روابط مشاركة موقّعة بـ HMAC محدّدة الصلاحية (`15 دقيقة` أو `ساعة واحدة` أو `24 ساعة` أو `7 أيام` أو `30 يوماً`).
- **محرر الصور المدمج (Canvas):** قص حر أو مقفول النسبة (`1:1` و`4:3` و`16:9`)، وتغيير الأبعاد بالبكسل (`أقصى عرض`/`أقصى ارتفاع`)، والتحكم بصيغة الإخراج (`JPEG`/`PNG`/`WebP`) والجودة، والتدوير بزاوية 90°، والقلب الأفقي والعمودي، والحفظ كنسخة أو استبدال الأصل.

| البيانات الوصفية ونقطة التركيز (`I`) | محرر الصور المدمج (`E`) |
| :---: | :---: |
| ![البيانات الوصفية ونقطة التركيز للملف](../images/file-metadata.png) | ![محرر الصور المدمج Canvas](../images/image-editor.png) |

- **التدويل العالمي ودعم RTL وإمكانية الوصول (WCAG 2.1 AA):**
  - **12 لغة واجهة مدمجة ودعم RTL تلقائي (`dir="rtl"`):** يدعم `en` و`tr` و`fr` و`de` و`es` و`ar` و`it` و`pt` و`nl` و`pl` و`ja` و`zh_CN`. تعكس العربية (`ar`) والفارسية (`fa`) والعبرية (`he`) والأردية (`ur`) وغيرها من لغات RTL تلقائياً التخطيط ومسار التنقل والأشرطة الجانبية وحواف OffCanvas باستخدام خصائص CSS المنطقية (`inset-inline` و`margin-inline`).
  - **سلامة الإدخال المركّب CJK / IME:** يمنع إطلاق `Enter` أو الاختصارات قبل أوانها أثناء كتابة النصوص الصينية أو اليابانية أو الكورية (`event.isComposing`).
  - **إمكانية وصول كاملة عبر لوحة المفاتيح وقارئات الشاشة:** حصر التركيز (`Tab`/`Shift+Tab`) داخل النوافذ المنبثقة وLightbox، والتنقل بالأسهم داخل قوائم السياق، ودلالات ARIA مثل `role="tree"` و`aria-expanded` و`aria-current`، واستعادة التركيز تلقائياً عند الإغلاق.
- **اختصارات لوحة المفاتيح (المرجع الكامل):**
  - تعمل جميع الاختصارات فقط عندما يكون التركيز داخل مدير الملفات، وخارج حقول الإدخال النصي (`<input>` و`<textarea>` و`<select>`)، وتحترم بصرامة **صلاحيات Voter** للمستخدم (`ui.keyboard_shortcuts: true`).
  - على macOS يعمل مفتاح **`Cmd (⌘)`** بسلاسة إلى جانب `Ctrl`.
  - **دعم لوحات المفاتيح الدولية وحماية IME:** تعتمد الاختصارات على رموز المفاتيح الفيزيائية (`event.code` مثل `Key*`) مع مطابقة احتياطية للأحرف بحيث تعمل على لوحات المفاتيح العربية وغير اللاتينية ولوحات غير QWERTY، مع بقائها صامتة أثناء الإدخال المركّب CJK IME (`isComposing`).

#### أ. عمليات الملفات والمجلدات
| الاختصار | الإجراء | الشرط / ملاحظة |
| :--- | :--- | :--- |
| `N` | إنشاء مجلد جديد | خارج سلة المهملات (صلاحية `create_folder`) |
| `U` | فتح نافذة الرفع | خارج سلة المهملات (صلاحية `upload`) |
| `F2` | إعادة تسمية العنصر | ملف أو مجلد واحد محدد (صلاحية `rename`) |
| `M` | فتح نافذة النقل / النسخ | عنصر واحد أو أكثر محدداً (صلاحية `move` أو `copy`) |
| `D` | تكرار الملف | **ملف واحد** محدد (صلاحية `clone`) |
| `I` | **مجلد:** لون وأيقونة المجلد / **ملف:** البيانات الوصفية ونقطة التركيز | عنصر واحد محدد (صلاحية `edit_metadata`) |
| `E` | فتح محرر الصور المدمج (Canvas) | صورة نقطية واحدة (`.jpg` أو `.jpeg` أو `.png` أو `.webp`) محددة (صلاحية `upload`) |
| `L` | نسخ رابط الملف إلى الحافظة | ملف واحد محدد (صلاحية `download`) |
| `S` | فتح نافذة رابط المشاركة الموقّع بـ HMAC | ملف واحد محدد (صلاحية `share` + `share.enabled: true`) |
| `Delete` | حذف العناصر المحددة (نقل إلى سلة المهملات أو حذف نهائي) | عنصر واحد أو أكثر محدداً (صلاحية `delete`) |

#### ب. التنقل والمعاينة
| الاختصار | الإجراء | الشرط / ملاحظة |
| :--- | :--- | :--- |
| `/` أو `Ctrl + F` | التركيز على حقل البحث | عند `show_search: true` (يعمل `Ctrl + F` أيضاً داخل حقول الإدخال) |
| `←` `→` `↑` `↓` | التنقل بين بطاقات الشبكة أو صفوف القائمة | — |
| `Enter` | **مجلد:** فتح • **ملف واحد:** فتح Lightbox في الوضع المضمّن، أو تأكيد الاختيار في وضع Modal/OffCanvas | — |
| `Space` | معاينة الملف المحدد في Lightbox | ملف واحد محدد |
| `Backspace` أو `Alt + ↑` | الصعود إلى المجلد الأعلى | عند التواجد داخل مجلد فرعي |
| `Alt + ←` / `Alt + →` | الرجوع للخلف / التقدّم للأمام في سجل التنقل | ينعكس تلقائياً في لغات **RTL** (العربية والفارسية والعبرية) |
| `R` | تحديث المجلد الحالي من الخادم (`?refresh=1`) | عند `show_refresh_button: true` |

#### ج. التحديد والحافظة وإغلاق الطبقات
| الاختصار | الإجراء | الشرط / ملاحظة |
| :--- | :--- | :--- |
| `Ctrl + A` | تحديد جميع العناصر الظاهرة | خارج سلة المهملات |
| `Ctrl + C` / `Ctrl + X` | نسخ / قص العناصر المحددة إلى الحافظة | عند عدم وجود نص مظلّل (صلاحية `copy` / `move`) |
| `Ctrl + V` | لصق ملفات/مجلدات الحافظة في المجلد الحالي **أو** رفع صورة/ملف مباشرة من حافظة نظام التشغيل | يعمل أيضاً أثناء فتح نافذة الرفع |
| `Shift + Click` / `Ctrl + Click` | تحديد نطاق / تبديل تحديد عناصر فردية | يمكنك أيضاً السحب على المساحة الفارغة للتحديد المربّع (Marquee) |
| `Esc` | **إغلاق ذكي على 4 مراحل:** 1) إغلاق القائمة/النافذة/Lightbox/الإعدادات/درج الجوال المفتوح ← 2) مسح التحديد ← 3) تفريغ الحافظة ← 4) إنهاء وضع ملء الشاشة المضمّن | يغلق الطبقة العليا فقط مع كل ضغطة |
| `Tab` / `Shift + Tab` | التنقل الدوري بين عناصر التحكم التفاعلية داخل نافذة منبثقة أو Lightbox (حصر التركيز) | — |
